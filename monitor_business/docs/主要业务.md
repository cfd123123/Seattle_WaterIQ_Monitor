# 主要业务说明

本文从**业务视角**说明本仓库在做什么：面向谁、解决什么问题、核心能力有哪些。技术细节与接口见 [api.md](./api.md)、[architecture.md](./architecture.md) 等。

---

## 1. 项目定位

本项目是一套 **水质与环境监测相关的业务系统**（工作名可概括为「水质业务监控 / monitor_business」），面向 **运营与技术人员**：在统一后台里管理 **监测站点**、拉取并维护 **USGS NWIS 瞬时水质（IV）数据**、在规则与模型辅助下做 **短时预测与异常识别**，并产生 **可确认、可关闭的告警**，辅以 **统计、地图与可观测性**，支撑日常监控与排障。

当前实现以 **美国地质调查局（USGS）Puget Sound 一带站点与 IV 数据** 为典型场景；架构上站点与参数可扩展，不限于单一河流或固定 CSV。

---

## 2. 要解决的业务问题

| 问题 | 做法（业务层） |
|------|----------------|
| 监测点分散、数据来源多（NWIS、本地 IV 文件等） | 维护 **站点主数据**（编码、经纬度、可选 USGS `site_no`），与 IV/预测共用同一套标识。 |
| 需要知道「现在是否异常、是否该预警」 | 基于 **IV 时间序列** 做 **浊度双点阈值**、**单参数异常（IF）** 等规则，写入 **告警事件**，支持确认与关闭。 |
| 需要「未来一段趋势」辅助判断 | 通过 **短时预测**（Java 代理 Python）读取 IV 历史，输出预测值与可用性说明。 |
| 重任务不能拖垮在线 API | **批量预测、IV 刷新** 等可走 **异步任务 + 消息队列**，由独立 Worker 执行，状态可查询。 |
| 需要总览与追溯 | 提供 **统计总览/分布/趋势**、**地图上的站点与告警摘要**，并与 **指标、日志、链路追踪** 联动（可选）。 |

---

## 3. 核心业务对象（领域语言）

- **监测站点（monitor_station）**：业务上的「测站」，含站编码、展示名、地理位置、可选外部数据源 ID（如 USGS 8 位站号）。
- **告警（alert_event）**：一条可流转的告警记录（新建 → 确认 → 关闭），带严重度、规则码、说明等；与站点、USGS 参数等业务规则关联。
- **USGS 单参巡检记录（usgs_site_param_run）**：对某站某参数（如流量 `00060`、浊度 `63680`）一次 IV 巡检/异常判定过程的落库，用于统计与趋势。
- **异步任务（async_task）**：如 IV 刷新、批量预测任务的状态机（排队、执行中、成功/失败等），便于前端轮询或运维查询。

历史上曾设计「通用水质检测事实表」路径，**当前产品主线已收敛为 USGS/站点/告警/预测为主**；具体表结构见 [database-schema.md](./database-schema.md)。

---

## 4. 主要业务能力（用户能感知的功能）

1. **站点管理**：登记与维护站点，与 NWIS 站点存在性校验（可选）对齐。
2. **IV 数据刷新**：从 NWIS 拉取 IV、合并写入 CSV；可按配置在刷新后触发 **浊度阈值扫描**等后续动作。
3. **告警**：列表/筛选、确认、关闭；支持多种来源（浊度阈值、预测阈值、USGS 参数异常等，以实际规则为准）。
4. **短时预测**：按站号、参数、预测步长等请求预测结果。
5. **统计与地图**：总览、分布、按日趋势（与 USGS 系列告警/巡检统计口径一致，见 [stats-definition.md](./stats-definition.md)）；地图上展示站点与告警相关摘要。
6. **自动预测（可选）**：在配置开启时，按调度对已登记站点进行批量预测类任务（与定时任务配置一致）。

**AI 服务（`ai_service`）** 在业务上承担：**规则评分、预测、IV 拉取与维护、部分异常检测** 等；Java 侧负责编排、权限、持久化、任务与对外 API。

---

## 5. 部署与访问形态（简要）

- 开发时常见：**前端** 本地 Vite、**后端** Spring Boot、**AI** Python；数据库 **PostgreSQL**（或 H2）。
- 容器化时：**网关** 统一入口、`monitor-service` 提供业务 API、`task-worker` 消费队列、**ai-inference-service** 提供推理与维护接口；详见 [phase4-service-split.md](./phase4-service-split.md)。
